OPS243-A Doppler Radar Setup
============================

1. Install the library:
   
   git clone https://github.com/graeb/OmnipresenseRadar.git
   cd OmnipresenseRadar
   pip install -e .

2. Hardware connections:
   
   OPS243-A  →  Raspberry Pi
   TX        →  RX (GPIO 15)
   RX        →  TX (GPIO 14)
   GND       →  GND
   VCC       →  5V

3. Enable UART on Pi:
   
   Add to /boot/config.txt:
   enable_uart=1
   
   Remove console from /boot/cmdline.txt

4. Test the sensor:
   
   python ops243a.py

5. Enable in main.py:
   
   Uncomment lines ~70-76 (doppler sensor init)
   Uncomment lines ~115-117 (doppler thread start)

Done! The sensor will log speed data in cm/s.
